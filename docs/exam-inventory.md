# 本地408 PDF提取性盘点

对 `E:\workspace\考研真题\408计算机学科专业基础` 下的35份PDF做了本地提取检查。结果为30份可提取文字、4份没有可提取文字、1份部分页面文字稀少。2023答案PDF使用空密码AES加密；安装PDF加密支持后可以读取，导入后产生62个片段，覆盖第1–14页。部分页面含孤立Unicode代理码点，索引文本中会将其替换为U+FFFD并提示对应页码，原始PDF字节仍原样保存。2026真题及答案PDF共29页，导入后第1–16页产生32个片段；第17–29页仅能提取到每页6–16个非空白字符，会被标记并跳过。

四份没有可提取文字的PDF是2019、2021、2024和2025答案文件。检查仅统计PDF文字层的可提取字符，不表示图像、公式或排版已被理解，也不证明可提取文字没有错误。盘点没有调用OCR、没有抽取真题题目或答案；真题内容不进入公开评测题集。

可在本机重跑盘点：

```powershell
.venv\Scripts\python.exe tools\inspect_exams.py "E:\workspace\考研真题\408计算机学科专业基础" --output data\private\exam-inventory.json
```

工具只保存相对路径、SHA-256、页数、每页字符数、低文字页码和提取状态，不保存或输出正文。JSON位于被忽略的 `data/private/` 目录，不应发布。
