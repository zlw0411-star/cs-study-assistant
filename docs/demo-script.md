# 三分钟演示脚本

| 时间 | 操作 | 讲解 |
|---|---|---|
| 0:00–0:25 | 打开真题学习台，展示默认“操作系统”题库和筛选条件 | “这是一个本地真题学习台。默认练正式原卷，用题目检查自己第一轮基础复习后的薄弱点。” |
| 0:25–0:55 | 搜索进程或调度考点，从题目列表选一道题 | “我先独立做题。列表显示年份、题号和可能的知识点；这不是自动判卷。” |
| 0:55–1:20 | 展示题干文字和原卷页码图片 | “文字便于定位，最后以原卷图片核对题目。涉及图、代码和公式时要读原页。” |
| 1:20–1:45 | 点击“查看已有答案材料”，手动选择一页 | “答案是原有 PDF 材料，不由模型生成。答案页码要自己找，不假设和原卷页码相同。” |
| 1:45–2:15 | 将状态改为“需复习”，勾选错题，写一句错因，保存 | “状态、错题和笔记都由我自己判断。薄弱统计只汇总本地练习记录。” |
| 2:15–2:45 | 做完题后点击“做题后，开始重建原理”，写一段原理解释和一个变式推导，勾选“我已自行核对这两个记录”并保存；打开另一年份未练同考点题 | “我先独立完成再打开知识卡，用自己的话解释原理、改变条件推一遍。保存的是我的学习记录，接下来用没做过的同类题验证迁移。” |
| 2:45–3:00 | 勾选“包含回忆版”，展示警告后取消 | “回忆版默认不参与练习；它可能混有解析或缺字，所以必须单独确认并谨慎使用。” |

演示全程不调用 BGE 或 Ollama，不会自动给答案或判对错。`artifacts/demo/storyboard.mp4` 是旧版 RAG 界面的演示素材，不代表当前真题学习台，不能用于本脚本演示。当前真题学习台截图和短片仍待验收，完成后再补链接；短片若由静态截图组成，会在分镜说明中标清，不称为连续屏幕录像。真题页面截图只使用获准公开的自编演示材料，不发布工作目录里的私人原卷图像。
