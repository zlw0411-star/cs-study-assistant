# 通用资料分析验证记录

## 验证范围

通用网页阶段历史验证为 87 项，包含材料服务 12 项、分析服务 17 项、通用网页 UI 8 项、旧版功能 50 项。该数字不含之后新增的桌面验证；桌面集成后的当前全量结果为 105 项通过（见[桌面版验证记录](desktop.md)）。通用 Streamlit 页面覆盖空库状态、文件导入和去重后的资料选择、切换文档时报告与来源隔离、删除最后一份和删除后仍有资料两种情况、未配置时禁用分析、成功报告导出以及分析失败时保留已有报告。导出检查读取实际 Markdown/JSON 下载数据，核对来源索引、模型信息、警告和密钥不泄露。

在线分析的页面集成测试使用真实 `MaterialAnalyzer` 和 `OnlineAnalysisClient`，HTTP 由 `httpx.MockTransport` 模拟，校验请求路径、认证头、映射与最终报告生成，以及报告按资料存入本机。测试未调用真实模型服务，也未验证模型生成质量。

旧版 408 UI 烟雾测试改为启动 `legacy_exam_app.py`，覆盖其空库与既有学习流程。旧页面源文件完整保留；本次没有迁移、修改或删除原有 `data` 下的真题数据库和材料。

## 运行测试

```powershell
.\.venv\Scripts\python.exe -X utf8 -m pytest -q -p no:cacheprovider --basetemp=.tools/pytest-temp
```

本记录描述网页阶段的历史基线：当时独立复跑 87 项通过，1 条来自 jieba 依赖的 `pkg_resources` 弃用警告。桌面集成后的最终独立复跑为 105 项通过，仍有该条既有警告。`--basetemp` 指向已忽略的 `.tools` 临时目录，避免系统临时目录权限问题。

## 已知限制

PDF 只提取可选择文字；扫描页不做 OCR。复杂公式、图像、表格和版面结构可能抽取不全，需要对照来源原文。来源编号校验只能确认引用 ID 存在，不能证明摘要、知识点或建议正确。语义效果和真实服务兼容性仍需用户针对所选模型自行评估。
