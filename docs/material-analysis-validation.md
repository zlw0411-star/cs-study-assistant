## 两层模式补充

桌面本地模式从已存来源按规则识别章节，自动提供目录和导出，不调用模型、不写入智能报告表。无可靠标题时只按来源页/段落导航，不生成知识点或语义摘要。模式切换不会触发网络；只有“在线智能整理”按钮才发起模型请求。四格式完整流程在任何请求前检查本地输出与导出，智能完成后重新打开资料库，核对两层结果仍独立。智能报告损坏时本地层回退可用，不修改旧记录。规则准确性边界见[资料整理指南](material-organization.md)。

## 已知限制

PDF 只提取可选择文字；扫描页不做 OCR。复杂公式、图像、表格和版面结构可能抽取不全，需要对照来源原文。来源编号校验只能确认引用 ID 存在，不能证明摘要、知识点或建议正确。新增“原文标题”验证要求独立原文行证据，但 PDF 的断行不证明语义标题。处理数量和实际引用数量分别记录，均不代表语义覆盖率；完整未引用来源可通过桌面整理详情查看。语义效果和真实服务兼容性仍需用户针对所选模型自行评估。
