# 人工核对说明

运行真实评测后，人工检查相应 `artifacts/*-retrieval.jsonl`。逐题对照答案和检索到的原文片段，分别判断：

- **答案正确性**：正确、部分正确、错误、恰当拒答。
- **引用支撑性**：所有重要结论都有依据、部分有依据、没有依据、不适用。

有效引用编号只代表编号指向存在的检索结果，不代表段落真的支持答案。对无答案问题，应检查系统是否承认笔记不足、是否避免补造事实。系统在没有命中片段时自动返回拒答，与生成模型基于证据决定拒答，是两种不同情况；核对时需分别记录。

记录评审者、日期、评测JSONL、题目ID、两项判断及一句理由。统计分数时同时报告题数和分母。dev反馈与test分开保存，不要根据test题调参后仍将同一次分数称为独立测试结果。

题目与gold来源由AI协作在开发阶段预先编写标注，没有用被测系统答案生成gold。生成输出中的引用编号由程序校验，这不能代替人类复核。目前未做逐条人工核查，报告中的人工正确性和引用支撑性保留为空。AI辅助复核应明确标注为AI意见，不能标作人工评分。
