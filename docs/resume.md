面向已完成一轮基础复习的考生，基于 Python、Streamlit 和本地 SQLite 构建真题练习与薄弱点复盘流程。支持按科目、年份、考点和个人练习状态筛选题目，回看原卷与已有答案 PDF，手动修正分类，并保存错因、原理解释和变式推导记录。知识点记录与单题状态分开保存，以另一年份未练同类题检验迁移；不自动判卷或生成真题答案。

## 填写自己的贡献

按亲自完成的工作补全，不要把项目现有功能自动当作自己的独立贡献：

- 我负责 [具体页面 / 服务 / 数据结构]，用 [自己编写的改动] 实现 [可观察行为]。
- 我用 [自己实际运行的检查] 验证 [结果]；仍未评测的 [分类准确率 / 学习效果 / 其他指标] 不写成成果。
- AI 工具参与了 [代码草拟 / 复核 / 文档整理]；我亲自理解并修改了 [具体部分]，并通过 [运行或测试方式] 确认行为。

## 独立实现的判断

只有自己能解释设计取舍、亲自修改相关代码、运行检查并定位失败原因后，才将该部分表述为“独立实现”。如果主要在工具协助下完成，可写“AI 协作开发”或“在辅助下实现”，并说明自己实际负责的模块。解释清楚题目答案不等于能独立维护学习台代码，能运行项目也不等于已掌握分类效果。
