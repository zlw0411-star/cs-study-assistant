# 产品范围

## 当前目标

让用户把常见文字学习资料保存在本机，并在需要时通过自行配置的 OpenAI 兼容服务生成来源可核对的摘要、提纲、知识点和学习建议。默认不调用在线服务。

## 当前包含

- 导入文字 PDF、DOCX、TXT、MD，按文件内容去重、切换、删除，并显示字数、来源片段、页/段位置和提取警告。
- 展开每个来源片段原文；提纲和知识点引用来源编号，并在 Markdown/JSON 导出中附完整来源索引。
- 在线配置服务地址、模型名和密钥，支持 `CSA_ANALYSIS_BASE_URL`、`CSA_ANALYSIS_MODEL`、`CSA_ANALYSIS_API_KEY` 环境默认值。
- 仅由用户显式点击按钮时发送所选资料的可提取文字；成功报告按资料分别保存在本机。失败时保留该资料上一次成功报告。
- 导出 Markdown 或 JSON 报告、资料元信息和来源索引，不导出密钥。
- 将 AI 输出明确标记为需要结合来源核对；结构校验要求模型引用有效来源 ID。

## 不包含

- 扫描 PDF 或图像 OCR；全扫描 PDF 不支持文字分析。
- 自动判卷、评分、答案核验或推断客观掌握程度。
- 保证文字提取完整、AI 生成内容正确，或保证表格、图像和公式含义被理解。
- 无配置时的网络访问。在线分析会把整份可提取文字分批发送，可能发生多次请求和计费。

## 数据与后续方向

通用资料、原始上传内容和报告放入 `material.sqlite3`；旧版真题学习台仍由独立 `legacy_exam_app.py` 和 `exam.sqlite3` 使用。下一步可评估更易查找的来源定位、用户自选分析范围和本机模型适配，但应继续让在线发送动作显式且可见。

## 独立保留的旧版 408 功能

`legacy_exam_app.py` 保留原有题目导入、分类、复习记录和真题学习流程，使用 `scripts/start_408.ps1` 在 8502 端口运行。旧版真题范围和使用边界见 `docs/exam-api.md`、`docs/true-exams.md` 及真题学习报告；这些文档描述旧功能，不代表当前通用资料页面的产品范围。
