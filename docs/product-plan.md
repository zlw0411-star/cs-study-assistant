# 产品范围

## 当前目标

服务已经学过一轮基础、希望用 408 真题发现薄弱点的考生。主流程是“真题入口 → 重建解题原理 → 推导不同条件下的变式 → 用另一年份同考点新题检验迁移”。页面始终展示原卷页码和可查看的 PDF 原页。

## 当前包含

- 按数据结构、计算机组成原理、操作系统、计算机网络、年份、考点和练习状态筛选题目。
- 主科目按题号规则给出建议，考点由关键词辅助建议；题目可标记待复核并由学生手动修正，不展示或声称分类准确率。
- 从异年未练的同考点推荐项可直接切题，页面同步科目/年份/考点筛选并关闭答案预览。
- 默认练习 2009–2025 年正式原卷；2026 回忆版默认隐藏，用户显式包含后显示“未官方核验，含解析或文字可能不完整”的提示。
- 逐页查看成功导入的原卷和已关联答案 PDF。混合文字/扫描页的原卷可预览；全扫描原卷目前没有可提取文字，不能自动拆题导入。学生自行选答案页，不根据页码推测答案和原卷的对应关系。
- 保存学生自评的未练、需复习、“本题已理解”状态、错题标记、笔记和手动分类。
- 按当前可见原卷范围内的错题与复习状态列出“优先复习考点”，并展示自编知识卡和另一年份尚未练习的同考点题；没有练习记录时明确说明列表暂按未练题量排列。
- 每个考点保存一份“原理解释”和“变式推导”记录；学生自行确认已核对后，只保存为自评，不做自动验证。
- 知识卡默认不展开；学生先独立作答，主动点击“完成独立作答，开始重建原理”后才显示原理和迁移提示。
- 本题复习状态与知识点原理掌握分开：题目可自评为“本题已理解”，知识点仍需用新条件和新题检验。

## 不包含

- 自动判卷、自动生成真题答案或自动诊断用户的客观掌握程度。
- 将本地出现频次描述成真实考试预测，或将“本题已理解”表述成客观知识掌握率。
- 对扫描图像进行 OCR，或保证代码图片、公式和表格已解析完整。
- 当前页面中的 BGE、Ollama 或模型生成流程。旧 RAG 代码可以在未来单独评估，不是本产品主流程。

## 数据边界

原卷、答案和个人记录保存在本机。正式真题与回忆版应分别标记；回忆版需要对照可信原卷核验后才适合作为练习材料。公开仓库只放自编知识卡和代码，不放受限真题或答案。
