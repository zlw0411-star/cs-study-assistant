# 408 真题学习台

面向已经学过一轮基础、开始用真题查漏补缺的考生。默认不连接模型、不生成答案，也不自动判卷。学习记录和题目材料保存在本机。

## 启动

需要 Python 3.12。在 Windows PowerShell 的项目根目录运行：

```powershell
.\scripts\setup.ps1
.\scripts\start.ps1
```

如果 setup 没找到 Python 3.12，可先安装 Python 3.12，或指定解释器完整路径：

```powershell
.\scripts\setup.ps1 -PythonExecutable "C:\Path\To\Python312\python.exe"
```

应用在 `http://127.0.0.1:8501` 提供本机页面。常规启动不需要 Ollama、BGE、向量索引或外部模型服务。旧版 RAG 原型代码保留在 `study_assistant/core.py`，当前真题学习台不会调用它。

## 一轮真题练习怎么做

一轮基础复习完成后，选一个考点做三道题：先独立作答，再查看原卷页码并对照已有答案；错题标为“需复习”，写明概念混淆、漏看条件或推导错误等错因。接着重建解题原理，用自己的话回答“为什么成立、依赖什么条件”，再改变题设推导一个变式；每个考点的原理与迁移记录只需维护一次。然后换一个年份做同考点未练题，检验能否把原理迁移到新条件。能解释推导理由后，再把本题自评为“本题已理解”。页面不会自动判卷或推断客观掌握程度。

左侧可按主科目、年份、考点、练习状态、错题和待复核分类筛选。默认科目是操作系统。主科目由题号规则建议，考点由关键词辅助建议；学生可以手动修正，页面不声称分类准确率。异年同考点的新题可直接切换练习。“优先复习考点”按当前可见原卷范围的未解决错题和复习记录排序；尚无练习记录时暂按未练题量列出，做题并记录错因后再用它安排复习。这些个人记录不代表考试预测。

## 真题材料和已知限制

克隆仓库后题库默认为空：原始真题 PDF 和本机数据库不会随仓库提供。开发机私有资料盘点覆盖 2009–2025 年正式原卷（17 年、约 799 道题）和单独标记的 2026 回忆版（40 道选择题）；这些数字描述开发机本地材料，不是仓库附赠题目数量。首次运行后，请导入自己有权使用、含可提取文字的 PDF。全扫描原卷目前不能导入并拆题。

开发机的 2026 回忆版默认不进入练习列表；勾选“包含回忆版”后页面会显示“回忆版·未官方核验”的醒目提示。该材料可提取文字可能混入解析、存在缺字，综合题还可能位于扫描页，不应把它作为代表性真题推荐。

成功导入的原卷可按页渲染，混合文字/扫描页的原卷可以在题干边查看原页；全扫描原卷没有可提取文字，目前不能导入并自动拆题。扫描型参考答案可以逐页查看，答案页码由学生自行选择，不假设与原卷页码对应。题目中的图表、代码图片或复杂公式需结合原卷图像阅读。系统提供原文定位和知识点辅助，不能保证抽取文字完整，也不能自动求解或核验答案。

开发机原卷提取盘点记录：35 份 PDF 中，30 份可提取文字、4 份无可提取文字、1 份部分页面文字稀少；详见[本地 PDF 盘点](docs/exam-inventory.md)。这些私人原始试卷和答案留在开发机，不随代码提交。应用运行后在本机生成 `data/exam.sqlite3`；可通过 `CSA_DATA_DIR` 环境变量更改数据目录。

当前本地题库、分类建议数量和使用边界记录在[真题考点学习台数据报告](docs/exam-learning-report.md)。报告明确区分自编目录建议、AI辅助抽查关注点和人工核对结果；目前没有可用于宣称分类准确率的真人逐题评分。

## 导入自己的材料

在左侧“导入本地真题 PDF”添加有权使用的原卷，可选填年份，并明确选择历年原卷或回忆版。要关联已有答案 PDF，在页面底部选择对应原卷后导入答案材料。默认来源类型是正式原卷。给回忆版分类时请选择“回忆版（未官方核验）”。

导入会记录题目文本、页码、来源类型和可复核状态；导入警告会提示没有文字或文字较少的 PDF 页。每个文件最大 20 MB。UTF-8 / GB18030 限制不适用于这里的 PDF 题库；扫描型文件通过页面渲染查看，不做 OCR。

## 项目检查

安装开发依赖并运行测试：

```powershell
.\.venv\Scripts\python -m pip install -r requirements-dev.txt
.\.venv\Scripts\python -m pytest
```

真题服务接口见 [docs/exam-api.md](docs/exam-api.md)，产品范围见[产品计划](docs/product-plan.md)，代码学习路线见[八周学习指南](docs/learning-guide.md)。自编知识卡位于 `examples/knowledge_points.json`。
